# For AI agents

- Start with the [contributor guide](CONTRIBUTING.md#before-you-start). For code changes, follow the [shared style and analyzer rules](docs/dev/code-style.md).
- Write concisely and efficiently. Avoid rhetorical devices, emphatic language, persuasive phrasing, and unnecessary stylistic flourishes. Prioritize direct, neutral, and factual communication. Avoid tables, prefer sections and bulleted lists.
- Use code comments sparingly, the code itself is enough to explain functionality.
- Also use minimal amount of text in user interfaces, make use of tooltips and icons.
- Keep edits focused on the requested task. Match nearby code and confine cleanup to the files you change.
- Inspect the final diff after Rider cleanup and rerun relevant checks if cleanup changed the code. If Rider is unavailable, review the style rules manually and say so.
- Report which checks ran, any pre-existing warnings, and anything you could not verify. For changes that could affect solved motion, report the dump comparison or explain why suitable takes were unavailable.
